# Run and deploy your AI Studio app

## Run Locally

**Prerequisites:**  `Node.js`

1\. Install dependencies: `npm install`

2\. Set the `GEMINI\_API\_KEY` in the file `API\_Key\_List.txt` to run (Gemini model only support)

3\. Run the app: `npm run dev`

4\. Vist your local run on \[here](http://localhost:3000/)
